# 五档难度

2026-11-02，本地实现。首页直接显示商店槽位风格的难度面板，保留夜城背景和Logo；点击“开始挑战”直接进入选中难度，无二级选择页。难度必须逐档解锁：初始仅一星可挑战，正常通关后开放下一星。未解锁档可浏览，开始按钮禁用并显示需要先通关的星级；开始入口同时校验连续低档通关记录，不能直接跳过。抵达末波、失败、测试局或不连续的旧高档记录均不解锁下一档。暂不接首通奖励、装备槽门槛或秘宝解锁。

五颗星表示等级，共用 CSS 黑胶唱片。首页采用地块选择同款黑底霓虹流光边框、双切角的竖长矩形槽位；顶部Header为“选择难度”，下方依次为光盘、左右箭头与星级、最高进度、描述、金币收益和开始挑战。仅保留左右两个切换按钮，最低/最高档相应方向禁用。槽位比初版稍宽，黑胶直径放大为上一版的5/3。最高进度与描述共用面板背景，用横线分隔；波数居中显示在加厚的进度条上，不显示“尚未挑战”等状态文字。完成普通波记录进度，最终结算确认后记录通关。本地保存使用 `neon-difficulty-progress-1` 至 `-5`，不读取旧最高楼层作为难度进度。

倍率均相对原配置，不逐级累乘。BOSS战额外插入，内部终点层分别为15/21/22/27/33。普通波仍包含当前特殊房间。五星保持30普通波+3首领战的长度。

沿用90/150/225候选队列、场上威胁预算和浮桥容量；精英替换队列里的普通敌人，不额外增加总量。精英波优先于酒车/锯刃/轨道特殊房间，避免预定精英被特殊房间吞掉。一星每5波1只包边铁球；二星每5波2只；三星每4波2只，加入弹跳碰撞机；四星每4波3只，加入强建机器人；五星每3波3只，后10波4只。精英显示共享显存常驻的骷髅血条标识，复用原怪物模型。

基础池追逐无人机/脉冲哨机/扇射飞蛾，二星开放战斗机/激光眼/双发眼，三星骷髅机，四星隐形无人机；各类仍遵守原关内出现时间。正式难度过滤强建机器人普通出场，仅作为精英。

攻击倍率主要作用于普通射击冷却；激光只调整空闲时间，隐形无人机只调整暴露休息。蛇、噬菌体、大无人机和飞碟子机的射击休息、裁决者休息同步调整；蜘蛛保留既有跑位与攻击节奏。预警、技能演出、子弹飞速、移动速度保持原时序。血量覆盖普通怪和首领，噬菌体后续分裂继承已调整的剩余血量。

测试：`node tests/test-difficulty.cjs` 覆盖五档真实首领生成/死亡/结算/胜利、波数、精英、血量、冷却预警及收益。`node tests/preview-difficulty.cjs` 使用真实Edge/WebGL，覆盖320/390/1280视口首页直接展示、全部选择按钮、直接开始/暂停返回首页、精英骷髅模型、通关保存及重载。已查看三尺寸首页截图。

相关通过：语法检查、浮桥、宝箱、结算、隐形无人机。旧campaign/hex-campaign断言期望普通音乐，但当前已有syncMusic固定boss轨道；room-pressure期望首关60%近战，当前已有配置20%；drinks期望2秒后自动入店，当前已有结算等待点击。这些旧断言未绕过或改写，不宣称全量回归通过。未发布，未手机实机验收。

当前展示调整：最高进度区暂时hidden，不占布局空间；进度数据和解锁规则保留。黑胶改为银色虹彩光盘，带中心孔、内环、不同的反光角度和五套专属配色，中心标签为Lv1至Lv5。光盘与曲名位于渐变上半区，通过青色折线发光边界与下方星级选择分隔。

光盘外层新增独立光晕容器，按各档主题色生成柔光轮廓，避免光盘中心孔的mask裁掉外发光。CSS注册角度变量驱动盘面虹彩20秒匀速流动；标签与盘体位置保持固定。系统减少动态效果时停用虹彩动画，保留静态光晕。真实浏览器检查0/5秒虹彩背景变化、文字位置不变、三视口布局和减少动态效果分支。

`dist/game.js` 的 `DIFFICULTY_DISCS` 配置每档曲名和音频路径。难度选择页播放当前选中的曲目，进入挑战后沿用该曲。各曲目独立记录播放位置，空配置回退到 `audio/relentless-minor.mp3`。

`preview-menu-music.cjs` 用 Edge 验证五档实际音频播放和入场续播。`test-difficulty-music.cjs` 覆盖曲目切换、独立续播及空配置回退。

内环按参考图调整为黑色（盘面直径38%的内环），Lv文字下移避开黑环；外部光晕与虹彩流动保留。
