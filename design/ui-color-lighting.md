# 霓虹高塔 UI 色彩与光照规范 v2

预览：`http://127.0.0.1:4173/ui-color-lab.html`。独立空白样板，不加载游戏运行时，不写入存档。复用本页 CSS 变量和组件样式前，按具体界面作用域接入，避免全局覆盖。

## 形状保持

沿用商店的实体卡片、12px双切角、编号、顶部斜纹和几何物品轮廓。此次规范只定义色彩、材质明暗和状态，不重新设计游戏物品。

## 光照分层

1. 环境：深底叠加宽幅蓝紫/青色径向渐变。示例为紫 #6443C7 / 22% 与青 #169CB2 / 15%，渐隐至56%/60%。它们只照环境，面板仍是实底。
2. 受光：面板145度 #2D2A4B → #252442；顶部细亮边，底部暗边形成厚度。正文不叠发光、不加色散。
3. 发光：选中项、主按钮才允许柔光。光晕绘制在未切角的外层，内部保持清楚的实色边界；不得把整张面板透明化来模拟光照。
4. 亮芯：图标与小面积暖金资源承担最高亮度。默认约75–80%有色暗部、15–20%饱和重点、5%高亮点缀，作为构图起点而非机械配额。

## 样板范围与验证

样板包含装备普通/选中/锁定态、属性图标与进度、可用/禁用加点、保存/重置、暖色奖励。光照开关可对比有无环境光与选中光晕。所有交互只在本页内存生效。

`node tests/preview-ui-color-lab.cjs` 验证1440/390/320三尺寸无横向溢出、装备切换、开关、加点上限、保存与重置、无游戏运行时及零页面/资源错误。截图是桌面Edge浏览器检查，不代表手机实机验收。


## v2 / 项目滤镜与波普表面

- 直接加载项目 `post-process.js` / `post-process.css`，`#viewport` 包含完整样板DOM和纹理Canvas，共享阈值提取、模糊、加法合成的Bloom链。样板内存预设：强度0.52、阈值0.74、半径1.15；轻微色散0.12、扫描线0.012、暗角0.05，关闭镜头畸变。不会保存或覆盖游戏的后处理偏好。
- `ui-color-shader.js` 在介绍横幅、两张装备卡、属性Header、奖励卡上绘制五个小型WebGL表面。片元着色器结合青蓝/粉紫渐变、缓慢波动的色相权重、11px周期点阵和窄幅移动反光。普通装备保持低彩度，选中项提高色彩占比；文字在独立DOM上层。
- 斑点以约3px/s横向、1.7px/s纵向移动；色带和反光更慢。30fps上限，仅绘制可见表面，隐藏页面不绘制；减少动态效果时固定时间。支持WebGL上下文恢复；不可用时保留CSS实底渐变。
- 增加“动态波普纹理”开关；Bloom开关联动真实项目滤镜的辉光增益与外围光晕。青/粉图标、青紫粉主按钮、白色四角星亮芯作为闪亮重点。
- 浏览器回归新增：Canvas像素随时间变化、减少动态时像素稳定、纹理开关产生像素差异、真实Bloom增益关闭、全部纹理上下文GL错误0。

## v3 / 明亮色块与一体式Header

- 属性Header移除内嵌边距与独立切角，直接贴合属性窗口上边和左右边，沿用窗口外轮廓裁切。Header不再混入深紫底，使用明亮薄荷青至浅蓝渐变。
- 选中装备采用明亮青/粉实色渐变，价格栏同步浅青；未选中与锁定保持原状态层级。奖励卡改为亮粉至杏金渐变。
- 明亮表面统一采用深靛色或深莓色文字，以文字对比保证阅读，不通过压暗大色块换取可读性。原有白色文字加轻阴影方案保留在介绍横幅。
- 点阵强度减弱，避免破坏鲜亮底色；Bloom、动态色相、波普运动保持。CSS回退与着色器配色一致。

## v4 / 轮廓层级与局部厚度

- 大窗口：属性窗口采用顶部台阶、侧边内收与底部折线，约20个转折点；介绍横幅使用较少的宽幅台阶；奖励卡使用错位肩部和底部台阶。不是每个角都切相同尺寸。
- 中卡片：主武器右上大切角加底部小内收，设施左上/右下切角，锁定卡只保留左下小切角。同一组件切换选择状态时轮廓保持，不把形变作为选择反馈。
- 小按钮：普通操作仅左上切角，主操作右箭头，加点按钮只切右下角。小控件避免复杂折线，保留有效内容区。
- 细框1px，局部边条2–4px；大窗口只在侧边、底边与顶部各取短段加厚，不整圈加粗。
- `ui-color-frames.js` 使用同一套像素坐标生成CSS裁切与SVG边线；ResizeObserver随组件尺寸更新，避免单纯百分比拉伸改变切角深度。边线层pointer-events:none，不阻挡按钮，父窗口统一裁切Header和纹理。

## v5 / 波点色彩对照

- 样板新增四版同底色、同点径（11px周期）对照：原版压暗、白色32%、纯白100%、RGB互补色72%。点击对照卡将该方案应用到整页五个现有纹理表面，对照卡保留各自方案。
- 默认半透明白；原有动态、Bloom与纹理开关继续有效，配置仅在本页内存保存。对色为当前底色的RGB反相，作为视觉候选。
- Edge回归验证四方案像素各异、选择状态、三宽度无溢出及既有交互；已查看1440截图，本地未发布。
