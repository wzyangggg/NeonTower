画面调节：右上角“画面调节”使用小型折叠面板，每次仅展开一组参数；可实时开启/关闭后处理，分别控制辉光强度、阈值和扩散范围、扫描线强度与间距、暗角强度，以及 RGB 各通道开关/增益。默认轻量复古街机效果，参数自动保存在本机，可恢复默认。URL `?postfx=off` 强制关闭，`?postfx=bloom` 仅保留辉光。效果统一作用于游戏 UI 与其下方场景，调参面板位于效果层上方。

新增“街机镜头畸变”“环境遮蔽 AO”“主光源阴影”三组：曲率、AO强度/半径、阴影强度/光源方向/柔和度/偏移均可实时调节并自动保存。AO使用半分辨率场景深度与法线，阴影使用1024方向光阴影贴图和柔化采样；只影响三维实体，透明特效和HTML UI在其后叠加。最后的CRT曲面畸变包含UI；Canvas和地块摆放手势按曲面采样位置校正。关闭总开关或使用postfx=off会绕过这三项。

扫描线支持滚动速度（px/s）：正数向下、负数向上、0静止，默认4px/s；关闭扫描线/总开关时暂停滚动，参数自动保存。

## 本地运行

安装 Node.js 后，在项目根目录执行：

```sh
npm run dev
```

访问 http://127.0.0.1:4173 。无需 npm install，也没有第三方运行依赖。
可直接打开 dist/index.html 试玩，但继续开发建议使用本地服务器。

```sh
npm run check
npm test
```

测试使用 mock WebGL，检查玩法、坐标、交易和资源恢复逻辑；不能代替真实 GPU 编译、手机触控、音效和视觉验收。
